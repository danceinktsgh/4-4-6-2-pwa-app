# ward_dashboard_design.md｜普通病房（內外科）護理負荷儀表板構想

> 版本：v0.1（2026-10-15）｜與加護病房版（literature_TISS_vs_NAS.md 第六節）平行設計
> 原則：不做研究；除交班一鍵自評外不增加填寫；只用既有資料；只呈現次數；內科互比、外科互比。

## 一、普通病房的問題和加護病房不一樣

| | 加護病房 | 內外科病房 |
|---|---|---|
| 現行工具 | TISS、APACHE | 主要只有三班護病比 |
| 看不到的負荷 | 基本照護（翻身、清潔、看守、家屬） | **周轉量**加上**病人依賴程度**和**病情變化** |
| 可借用的國際架構 | NAS 的活動分類 | RAFAELA／OPC 的六個照護面向 |

**普通病房最大的盲點是周轉。** 三班護病比算的是「病人數」，但同一張床白天出院一位、下午再入院一位，在護病比上只算 1 人，實際卻是兩份工作：出院衛教、單位整理、入院評估、新醫囑。

## 二、文獻依據（已於 sources.md 查核，摘要層級）

| 論點 | 依據 |
|---|---|
| 人力不足與病人死亡相關 | Aiken 2014 Lancet：每位護理師多照顧 1 名病人，30 天死亡 OR 1.068 |
| **高周轉的班別本身就是風險** | Needleman 2011 NEJM：每暴露一個高周轉班，死亡 HR 1.04；RN 人力低於目標 8 小時以上的班，HR 1.02 |
| 用平均值訂人力會低估 | Griffiths 2020（英國 SNCT 評估研究）：約 26% 的病房日人力不足 15% 以上；小單位、單人房多的單位需要更多護理時數 |
| 漏失照護普遍 | Ball 2014 BMJ Qual Saf：86% 的護理師表示上一班至少有一項照護沒做完 |
| 依病人照護強度看負荷，比只看病人數略佳 | Fagerström 2018 BMJ Open（芬蘭 RAFAELA）：負荷高於最適水準時，病安事件 OR 1.24、死亡 OR 1.43。**但作者自認只比護病比「略佳」** |
| 護理師直接照護時間有限 | Westbrook 2011：直接照護只占工時 20–25% |

## 三、借用 OPC 六面向的「架構」，對應既有資料

> 只借用六個面向的分類概念，**不複製 OPCq 的題目與計分**，所以沒有授權問題，也不能稱為 RAFAELA。

| OPC 面向 | 可從既有資料撈取的指標（每單位、每班） | 預期來源 |
|---|---|---|
| 1. 照護計畫與協調 | 新入院、出院、轉入轉出、術後返室人次；會診數；出院準備服務個案 | 入出轉系統、醫囑 |
| 2. 呼吸、循環與病情症狀 | 早期預警分數（NEWS／MEWS）達警示值的人數；生命徵象須密集測量者（q1h、q2h）；氧氣治療、抽痰；快速反應小組呼叫次數；輸血次數 | 護理資訊系統、醫囑 |
| 3. 營養與用藥 | 實際給藥次數，其中靜脈、高警訊藥物、胰島素的次數；管灌、全靜脈營養人數 | 給藥執行紀錄 |
| 4. 個人衛生與排泄 | 日常活動依賴（例如 Barthel 低分）人數；導尿管、造口、失禁人數；傷口換藥次數 | 護理資訊系統 |
| 5. 活動、睡眠與休息 | 高跌倒風險人數；約束人數；譫妄或失智躁動人數；翻身紀錄次數 | 護理資訊系統 |
| 6. 衛教、出院指導與情緒支持 | 出院衛教紀錄次數；安寧、臨終照護人數；家屬會談紀錄 | 護理紀錄 |
| （加上）隔離 | 接觸、飛沫、空氣隔離人數 | 感管系統 |
| （加上）外出 | 護送外出檢查、手術的人次 | 醫囑、排程系統 |

## 四、儀表板第一版要呈現的畫面

1. **護病比之外的負荷落差**：同樣符合 1:6 的白班，A 病房每位護理師有 2 個新入院、1 個出院、30 次給藥；B 病房只有 0 個新入院、15 次給藥。
2. **周轉熱點**：哪些單位、哪些班別（通常是白班下午到小夜）入出院最集中。
3. **高依賴病人的集中程度**：跌倒高風險、約束、譫妄、日常活動依賴的病人，是否集中在特定病房。
4. **人力軸（對照用）**：實際上班人數、加班時數、未休特休。

## 五、要注意的地方

1. **醫囑不等於已執行**：給藥、換藥都要用「已執行」紀錄。
2. **紀錄完整度不同**：某病房數字低，可能只是紀錄習慣不同。第一版要先檢查各單位的資料完整率。
3. **內科與外科不互比**：外科以手術前後、周轉為主；內科以高齡、依賴、長住院為主，型態不同。
4. **不換算分鐘或員額**：沒有本院實測的時間權重，第一版只呈現次數與落差。
5. **交班一鍵自評（已決定納入，2026-10-15）**：每位護理師交班時點選「本班負荷 −3 到 +3」（0＝剛好），可再點選主要原因（入出院多／病人依賴高／病情變化／人手不足／其他），只需數秒。
   - 用途：對照客觀數字，找出「數字看起來還好、但護理師覺得很重」的單位和班別；累積後可估計各單位「多少負荷算剛好」（芬蘭 RAFAELA 的校正概念）。
   - 執行：先以紙本勾選或不含個資的表單試行，待資訊室放進交班單後改為系統填寫。
   - 原則：只看單位、班別的分布，不用於個人考核；若出現系統性偏高，以和客觀數字的相對落差解讀。
